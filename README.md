# 🛡️ Smart Shelter Design & Management System (DRDO-Centric Concept)

An interactive web application built with **Streamlit** to simulate, visualize, and analyze smart shelter frameworks, environmental parameters, and life-support metrics tailored for defense and extreme environment applications.

🔗 **Live App:** [smartshelter-drdo.streamlit.app](https://smartshelter-drdo.streamlit.app/)

---

## 🚀 Features

* **Real-Time Parameter Monitoring:** Simulated telemetry tracking for internal climate, life-support reserves, and structural integrity.
* **Interactive Controls:** Adjust external environmental inputs (such as external temperature, altitude, or threat levels) to test shelter response thresholds.
* **Visual Dashboards:** Clean graphical metrics powered by Streamlit components to evaluate power consumption, oxygen generation, and waste management cycles.
* **Optimized UI:** Responsive layout configured for seamless usage across desktop and mobile browsers.

---

## 🛠️ Tech Stack

* **Python 3.9+**
* **Streamlit** (Frontend & App Framework)
* **Pandas / NumPy** (Data handling & simulations)
* **Plotly / Matplotlib** (Interactive visualizations)
